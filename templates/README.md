# Templates

Reusable starting points.

- [task-register.md](task-register.md): one current execution record, written by delivery-lead, including dependencies, gates, decisions and release handoff.
- [agent-assignment.md](agent-assignment.md): capability, baseline, criteria, tools/skills, boundaries, acknowledgment and evidence for an implementer or reviewer assignment.

- [til-note.md](til-note.md): a "today I learned" note, shaped so it can become a blog post. Used by the [til](../skills/shared/til/SKILL.md) skill.
- [feature-doc.md](feature-doc.md): a visual feature document skeleton. Used by the [feature-doc](../skills/developer/feature-doc/SKILL.md) skill.
- [pr-description.md](pr-description.md): a pull or merge request description skeleton. Used by the [pre-push-review](../skills/developer/pre-push-review/SKILL.md) skill.
- [digest-config.md](digest-config.md): the config skeleton the user fills in for the [weekly-digest](../skills/shared/weekly-digest/SKILL.md) skill.
- [issue-description.md](issue-description.md): an issue description skeleton. Used by the [planner](../agents/planner.md) agent.
- [doctor-report.md](doctor-report.md): a private environment report skeleton with live sign-in-only and offline examples, following the [environment check specification](../docs/environment-check.md).
- [validation-report.md](validation-report.md): offline validation evidence, incomplete checks and follow-up under the [validation specification](../docs/offline-validation.md).

- [project-config.example.json](project-config.example.json): synthetic project-private configuration starter; copy and use it under the [private configuration guidance](../docs/private-configuration.md).
