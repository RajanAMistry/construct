# Construct

A small collection of employer-neutral, reusable skills, agent guidance and working methods.

Start with [construct.md](construct.md) for scope, indexes, status definitions and contribution rules. Read [AGENTS.md](AGENTS.md) before making changes.

The repository contains reusable material at evidence-based maturity levels; no skill is currently claimed as tested. See the [skill index](construct.md#skill-index) for current status and verification evidence. Add one useful, reviewed item at a time.

No software licence has been selected. Public visibility does not grant an open-source licence.
